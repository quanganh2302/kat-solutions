# Delivery roadmap

## Phase 1 — Visual website

- Establish the Next.js project and Figma-derived design system.
- Implement Home, Projects, About, and Contact as Vietnamese static pages.
- Match desktop, tablet, and mobile frames.
- Keep product content local and typed.

## Phase 2 — Lead capture

- Add validated contact submission, email delivery, anti-spam protection, and success/error states.
- Decide whether contact requests need storage or CRM integration.

## Phase 3 — Content and language

- Select a headless CMS for non-developer editing.
- Move page and demo-link content to the CMS.
- Add reviewed English content and locale routing.

## Phase 4 — Optional intelligence

- Define a constrained chatbot knowledge source, privacy rules, model/provider, budget, and escalation path before implementation.
